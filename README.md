Open Rack

Open Rack is an open-source collection of 3D-scanned server rack chassis designed to make hardware adaptation and chassis reuse easier.

The project provides 3D scans and optimized models of existing server chassis, allowing the community to design and share replacement or modified chassis sheets. These sheets can adapt proprietary or otherwise unsuitable server chassis to commonly available hardware standards such as:

ATX power supplies

Standard ATX I/O shields

PCI/PCIe expansion slots

Other standard motherboard and hardware interfaces

The Idea

Finding a server chassis that perfectly fits your hardware can be surprisingly difficult. Many server systems use proprietary dimensions, backplanes, power supplies, I/O layouts, and expansion configurations. Suitable replacement chassis may be unavailable, expensive to ship, or simply no longer manufactured.

Instead of throwing away an otherwise useful chassis, Open Rack aims to make it possible to adapt it to your hardware.

The general process is:

Start with a 3D scan of an existing server chassis.

Create an optimized, editable 3D model from the scan.

Modify the relevant chassis sheet or I/O backplane to accommodate the desired hardware.

Manufacture the resulting sheet using an appropriate fabrication method.

Drill out the original chassis rivets.

Remove the old sheet and install the new one using rivets.

This turns otherwise incompatible or proprietary hardware into a reusable foundation for a new system.

Why Open Rack?

Open Rack addresses several common problems:

Proprietary chassis: Adapt hardware that would otherwise only fit its original system.

Limited availability: Avoid hunting for increasingly rare matching chassis.

High shipping costs: Reuse locally available hardware instead of ordering specialized cases internationally.

Waste reduction: Give old server hardware and chassis a second life.

Time savings: Start from an existing chassis rather than designing an entire enclosure from scratch.

Community-driven design: Share scans, CAD models, modifications, and manufacturing files with others.

Community Manufacturing

The goal is not just to collect scans, but to create a workflow where anyone can contribute improvements and hardware adaptations.

A contribution might include:

A new 3D scan of a server chassis

A cleaned and optimized CAD model

An ATX-compatible modification

A new I/O shield layout

A PCI/PCIe expansion-slot modification

Manufacturing-ready sheet-metal drawings

DXF or other fabrication files

Documentation for installing the replacement parts

Over time, Open Rack can become a library of reusable chassis designs and adaptations for hardware that would otherwise be difficult or expensive to reuse.

Open Hardware, Reuse, and Repair

Open Rack is ultimately about making existing hardware more adaptable.

Rather than treating proprietary chassis dimensions as a dead end, the project provides the digital models and community knowledge needed to modify them. The intention is to combine 3D scanning, CAD, open design, and local manufacturing to extend the useful life of server hardware.

Scan it. Design it. Manufacture it. Reuse it.
